Privacy

Last updated: September 29, 2026.

This website

This site has no account system, contact form, analytics SDK, advertising pixels, or application cookies. It does not collect a mailing list. Downloads and page requests are handled by the site host or release-file host, which can receive IP addresses, browser headers, and request logs.

This website is hosted on Render. Installer and portable downloads are hosted on GitHub Releases. The hosting providers have their own terms and privacy practices for requests they receive.

The browser

Normal history, bookmarks, settings, cookies, and restored tabs are saved locally in Velocinder’s profile. No application telemetry is implemented. Search terms go to the selected search provider, and website visits go to those sites. Their privacy policies apply.

Private tabs

Private tabs use a separate in-memory session and are excluded from saved history and restored tabs. Downloads and bookmarks you deliberately create can remain on disk. Private browsing does not make you anonymous to websites or network operators.

Ad-block filter updates

Bundled EasyList and EasyPrivacy work immediately. Manual filter updates contact official EasyList endpoints. The blocker does not transmit browsing history to this project.

Before public launch

Velocinder Labs is a provisional brand. The operator’s legal identity and a working contact method still need to be supplied before this document can serve as a finalized public business privacy notice.
