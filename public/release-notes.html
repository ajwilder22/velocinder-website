Release notes

Version 1.0.0 · September 29, 2026 · Windows x64 · Early release

Initial browser release

  • Chromium tabs, navigation, downloads, popup routing, context menus, and developer tools.
  • Google default, 34 search destinations, and custom search URLs.
  • Built-in EasyList and EasyPrivacy blocking, cosmetic hiding, website exceptions, filter updates, and custom rules.
  • Sleeping tabs, soft memory budget, session network limits, background muting, and cache cleanup.
  • Bookmarks, history, private tabs, session restoration, speed dial, and accent colors.

Download options

The installer includes directory selection, shortcuts, and an uninstaller. The portable version runs from its extracted folder. Both use the same browser runtime. No silent installation is triggered by this website.

Download SHA-256 checksums.

Known limits

No hard CPU cap, automatic updater, built-in VPN, password manager, or Chrome account sync. Some DRM streaming, Google authentication, and Chrome extensions can differ. Sleeping a tab can lose unsaved work. Audible tabs stay awake. Ad blocking cannot remove every ad.

Verification

Browser tests covered local native browsing, renderer isolation, tabs, search configuration, bookmarks, sleeping, downloads, private-tab persistence, network settings, ad blocking, cosmetic hiding, and website exceptions. No comparative speed benchmark was performed. Universal compatibility is not established.

The installer was built with NSIS. End-to-end installation and uninstallation on a clean Windows machine remain a release check.
